# SDGs Green Asian Games Proposal Votes

綠色亞運提案匿名投票系統：6 組提案、每組 60 秒、手機匿名投票（贊成／不贊成＋贊成理由），時間到大螢幕同時揭曉票數與所有理由。

鳳新高中英文科李姬慧老師 X AI 彙整製作

## 網頁

| 頁面 | 用途 |
|---|---|
| `index.html` | 入口 |
| `vote.html` | 學生手機投票（可用 `?code=XXXXX` 自動帶入投票碼） |
| `screen.html` | 老師投影大螢幕：開始倒數、開票、理由牆、總結果 |
| `cards.html` | 列印投票卡（每張含投票碼＋QR Code） |

`config.js` 的 `API_URL` 留空時是**示範模式**：資料只存在同一台電腦的瀏覽器，大螢幕會有虛擬同學投票，方便預覽。

## 連接 Google Sheets 後台

1. 建一份新的 Google 試算表 → 擴充功能 → Apps Script，貼上 `gas/Code.gs` 全部內容並儲存。
2. 回到試算表重新整理，選單「🗳️ 投票系統」→ ① 初始化工作表（預設老師密碼 `sdgs2026`，可用 ③ 修改）。
3. 在「提案」工作表填入 6 組提案。
4. 選單 ② 產生投票碼（人數＋幾張備用）。
5. Apps Script → 部署 → 新增部署作業 → 類型「網頁應用程式」：執行身分「我」、存取權「所有人」→ 部署，複製網址。
6. 把網址貼到 `config.js` 的 `API_URL`，推上 GitHub。

> 修改 `Code.gs` 後要「管理部署作業 → 編輯 → 新版本」，網址才會更新到新程式。

## 匿名設計

- 投票碼只用來確認「這一輪投過了沒」，不記錄投了什麼、什麼時間投。
- 票數只存總數；贊成理由只存「組別＋文字」，揭曉時順序打亂。
- 投票卡隨機發放，不記錄誰拿到哪一張。
